# 🎮 SwitchMath — Nintendo Switch Rewards

A kid-friendly web application that helps children master their times tables using **spaced repetition learning**, while rewarding practice with bonus screen time delivered directly to a **Nintendo Switch** via Nintendo's Parental Controls API.

> **Disclaimer:** This is an independent community project. It is not affiliated with, endorsed by, or connected to Nintendo. "Nintendo Switch" is a trademark of Nintendo.

---

## Features

- 🎯 **Full Times Tables Coverage**: All 121 facts from 2×2 to 12×12, with options to exclude easy tables (2×, 10×, 11×).
- 🔁 **Spaced Repetition Engine**:
  - Wrong or hesitant answers (> 4s) are re-queued 3 questions later for immediate reinforcement.
  - Leitner 5-box system promotes facts through mastery levels based on consecutive correct answers.
- 🎮 **Nintendo Switch Integration**:
  - Automatically adds bonus playtime (e.g. +5 minutes) to a linked Nintendo Switch after a configurable number of correct answers.
  - Powered by [`pynintendoparental`](https://github.com/pantherale0/pynintendoparental).
- 🏦 **Time Bank**: Earned screen time is banked and can be redeemed to the Switch on demand, with a cute animated piggy bank mascot.
- 🛡️ **Parental Safeguards**:
  - Configurable daily cap (e.g. max 60 minutes per day).
  - Configurable exchange rate (e.g. 10 questions = 5 minutes).
  - Toggle individual times tables on/off from the Settings panel.
- 📊 **Mastery Map**: Interactive colour-coded grid tracking accuracy, speed, and mastery level for every fact.
- 📱 **Tablet Friendly**: Large numbers, on-screen keypad, confetti celebrations, and keyboard support.
- 🐳 **Self-Hosting Ready**: One-command Docker Compose setup for a home server, Raspberry Pi, or NAS.

## Quick Start

### Prerequisites

- **Python 3.10+** (3.12+ recommended)
- [**uv**](https://docs.astral.sh/uv/) — fast Python package manager

### Install & Run

```bash
# Clone the repository
git clone https://github.com/<your-username>/switchmath.git
cd switchmath

# Install dependencies
uv sync

# Copy and configure environment variables
cp .env.example .env

# (Optional) Set up Nintendo Switch connection interactively
uv run python scripts/test_nintendo.py

# Start the web application
uv run python -m app.main
```

Open **http://localhost:8000** (or `http://<your-local-ip>:8000` on a tablet).

## Nintendo Switch Setup

The app connects to Nintendo Switch Parental Controls to deliver bonus playtime. Setup is optional — the times tables quiz works standalone without it.

1. Run the interactive setup script:
   ```bash
   uv run python scripts/test_nintendo.py
   ```
2. The script opens an official Nintendo login URL. Sign in with the Nintendo Account managing your Switch Parental Controls.
3. On the "Select this person" page, **right-click the button → Copy link address** (the URL starts with `npf...://`).
4. Paste the URL into the terminal. The script saves your `SESSION_TOKEN` to `.env` and verifies the connection.

---

## Environment Variables

| Variable | Required | Description |
|---|---|---|
| `SESSION_TOKEN` | For Switch rewards | Nintendo OAuth session token (generated by `scripts/test_nintendo.py`) |
| `SELECTED_DEVICE_ID` | No | Target Switch device ID if you have multiple consoles |
| `DATABASE_PATH` | No | SQLite database path (default: `data/rewards.db`) |

Reward settings (questions per reward, minutes per reward, daily cap, active tables) are managed through the **Settings** panel in the web UI.

## Docker

```bash

cp .env.example .env

# Build and start
docker compose up -d
```

Data persists in `./data/` and credentials in `.env` (both mounted as volumes, never baked into the image).
